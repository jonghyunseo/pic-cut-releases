사진과 선택 기록

Pic Cut의 사진 비교·선택은 기기에서 처리합니다. 앱은 자체 서버에 사진이나 선택 기록을 전송하지 않습니다. 묶음과 선택 상태는 앱 저장 공간에 보관합니다. 다른 앱에서 임시 접근 권한으로 공유한 사진은 다시 열 수 있도록 앱 내부에 사본을 보관할 수 있습니다.

추천

추천 탭을 사용하면 허용한 사진의 추가 시점·촬영 정보로 연속 촬영 사진을 찾습니다. 사진 접근 범위 안에서 기기에서만 처리하며 서버로 전송하지 않습니다. 추천 숨김·가져오기 기록을 앱 저장 공간에 보관합니다. 추천에서 가져오기는 작업 묶음에 연결하는 동작으로 원본을 이동하거나 삭제하지 않습니다.

저장·공유·원본 정리

저장을 실행하면 선택한 사진의 사본이 갤러리의 PicCut 폴더에 생성됩니다. 공유는 사용자가 선택한 다른 앱으로 사진을 전달합니다. 비교 중 제외는 원본 삭제가 아니며, 원본 이동·삭제는 ‘제외 사진 정리’에서 별도로 실행합니다.

웹사이트와 업데이트

이 사이트는 GitHub Pages에서 제공하며 별도의 방문 분석 도구나 광고 스크립트를 사용하지 않습니다. 글꼴과 예시 이미지는 사이트에서 직접 제공합니다. 호스팅과 APK 다운로드에는 GitHub의 개인정보 처리방침이 적용됩니다. Obtainium 연결 버튼을 누르면 Obtainium의 연결 페이지로 이동합니다.
